# OMER Admin — planned structure

The storefront is ready for an admin layer.

Recommended admin functions:

- Create/edit products
- Upload photographs
- Set print/postcard variants
- Set edition size
- Set stock
- Mark products as limited/new/sold out
- Manage prices
- View orders
- Update fulfilment status
- Export orders
- Manage newsletter subscribers

For security, the admin should be hosted separately from GitHub Pages and require authenticated server-side access.
